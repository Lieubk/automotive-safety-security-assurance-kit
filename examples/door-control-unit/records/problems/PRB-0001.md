## Description

SYQT-0002 (SYR-0002): the window is closed from fully open by a press beyond the second detent at 13.5 V and 23 C. The bench reports the times 4.4 s, 4.4 s, 4.3 s, 4.4 s and 4.4 s; the criterion is at most 4.0 s in each of five runs. Environment: door bench, B-sample unit B-04, motor 03, software 1.0. Reproduce with SYQT-0002 on build BLD-0002.

## Cause and impact

The speed ramp of the software element, a calibration value, is set so that the motor reaches its speed late in the stroke. The motor itself delivers the speed that SYR-0002 needs (the share of the motor in the closing time of SYE-0003 is met). Impact: SYR-0002 is not met; the other nine qualification cases passed, so no other requirement is affected. The cause lies in the calibration data of the software element, not in a requirement, the architecture or the test.

## Resolution

The software department changed the calibration of the speed ramp and delivered software 1.0.1; no function, interface or code structure changed. Integration step door-bench and the qualification were run again on the new build BLD-0003: RUN-0004 (4 passed) and RUN-0005 (10 passed, SYQT-0002 within the limit). No baseline held SYE-0002 yet, so no change request was needed.
