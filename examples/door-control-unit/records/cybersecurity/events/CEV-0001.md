## Description

The basic software supplier reports in its bulletin of 2026-11-05 that the seed-key algorithm of the bootloader version used in the unit is weak: a key can be derived from observed seeds. The bulletin names the bootloader version that the software element SYE-0002 contains.

## Triage

Relevant: the bulletin names a part and version of the unit (trigger "component and version" of PLN-0006). One weakness follows, WKN-0001. The OEM contact O. Engineer is told as information sharing (CMR-0003).
