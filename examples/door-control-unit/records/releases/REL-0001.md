## Release note

Release note, DCU-F release B1 (B-sample)

Content: B-sample units of the front door control unit DCU-F with the window lift motor, built from the release candidate baseline BL-0001 (tag dcu-f-b1-rc). The software element is "power window software" of our software department in version 1.0.1; the units were tested as system build BLD-0003. The system requirements SYR-0001 to SYR-0010 are all verified in the qualification run RUN-0005 (10 of 10 passed).

Changes since the first qualification run: the calibration of the motor speed ramp was changed (software 1.0.1) because the one-touch closing time was 4.4 s against the limit of 4.0 s (PRB-0001, closed).

Known issue: the bootloader of the basic software supplier contains a weak seed-key algorithm (WKN-0001, bulletin of 2026-11-05). Reprogramming needs the vehicle diagnostic port and the OEM's tester credentials; the feasibility is low. The risk is retained for B1 (CLM-0001); the corrected bootloader goes into release B2.

Open items: none.
