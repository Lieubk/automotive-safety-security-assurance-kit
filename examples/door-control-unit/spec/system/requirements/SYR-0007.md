## Statement

The door control unit shall make its fault memory readable through the vehicle diagnostic interface.

## Verification criteria

With a fault stored in the unit, the diagnostic tester of the bench reads the fault memory through the diagnostic interface. The fault code and its status are returned in the response; reading does not change the stored fault.

## Analysis

The diagnostic protocol and the fault codes are those of the OEM's diagnostic specification, which is not part of the delivery. Reading the fault memory exposes data over the vehicle diagnostic port.
