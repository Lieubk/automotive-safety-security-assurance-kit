## Statement

The door control unit shall make its fault memory erasable through the vehicle diagnostic interface.

## Verification criteria

With a fault stored in the unit, the diagnostic tester of the bench sends the erase request through the diagnostic interface. A following read of the fault memory returns no stored fault.

## Analysis

Erasing is a write access over the diagnostic port; the OEM's tester credentials decide who may do it. Which credentials are required is in the OEM's diagnostic specification.
