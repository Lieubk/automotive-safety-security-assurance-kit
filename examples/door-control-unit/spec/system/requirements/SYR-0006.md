## Statement

The door control unit shall receive the lock command and the unlock command of the body controller as messages on the body CAN.

## Verification criteria

The bench's bus simulation sends the lock command and the unlock command as defined in the OEM's message matrix. The unit acknowledges each message on the body CAN and executes it; a message with a wrong checksum is not executed.

## Analysis

The message matrix of the body CAN is the OEM's and not part of the delivery; it is needed before the bus simulation can be set up. The load of the body CAN is risk RSK-0002.
