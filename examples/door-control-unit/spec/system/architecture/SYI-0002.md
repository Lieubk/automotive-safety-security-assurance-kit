## Definition

End points: the door switch panel (SYE-0004) as LIN slave and the door control unit as LIN master, evaluated by SYE-0002 through the LIN transceiver of SYE-0001. The provider of the switch states is the switch panel.

| Property | Value |
|---|---|
| Bus | LIN, 19.2 kbit/s |
| Frame | one frame per 20 ms with the state of each switch: 0 not pressed, 1 first detent, 2 second detent, 3 not available |
| Time-out | a frame missing for 100 ms means no switch is pressed |
| Checksum | enhanced LIN checksum; a frame with a wrong checksum is discarded |

## Dynamic behavior

After the time-out the unit stops an automatic movement started by a press beyond the second detent.
