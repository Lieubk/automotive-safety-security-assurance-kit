## Definition

End points: the body controller of the OEM (outside the system) and the door control unit, received by the software element SYE-0002 through the CAN transceiver of SYE-0001. The OEM's message matrix of the body CAN is the definition of the bus; this system uses the signals below. The provider of the lock commands is the body controller, the provider of the acknowledgement is the door control unit.

| Property | Value |
|---|---|
| Bus | CAN, 500 kbit/s |
| Lock command message | cycle on event, signal LockCmd: 0 no command, 1 lock, 2 unlock, 3 not available |
| Lock acknowledgement | sent within 20 ms after the command, signal LockAck: 0 not executed, 1 locked, 2 unlocked |
| Protection | the message carries a checksum; a message with a wrong checksum is discarded without reaction |
| Loss | after 500 ms without the cyclic status message of the body controller the unit keeps the lock state |
| Diagnostic requests | carried on the same bus in the diagnostic frames of the OEM's diagnostic specification |

## Dynamic behavior

The unit executes a command once per message; a repeated message of the same command causes no further movement.
