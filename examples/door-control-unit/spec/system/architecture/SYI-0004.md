## Definition

End points: the Hall sensor of the window lift motor (SYE-0003, provider) and the capture input of the door ECU hardware (SYE-0001), evaluated by SYE-0002.

| Property | Value |
|---|---|
| Signal | two square-wave channels with 90 degrees phase shift, 5 V logic level, 0 V low, tolerance +/- 0.5 V |
| Resolution | one pulse edge per 0.5 mm of glass travel |
| Frequency | 0 Hz (standing) to 400 Hz |
| Duty cycle | 50 percent +/- 10 percent over the temperature range; at -40 C open item with the motor supplier |
| Failure | a standing motor delivers no edges; a cut line holds the level, which the software treats as a standing window |

## Dynamic behavior

The signal is valid 5 ms after the motor starts to turn.
