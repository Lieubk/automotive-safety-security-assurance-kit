## Preconditions

Complete system on the door bench in the temperature chamber, supply 13.5 V; the housing of the unit is held at -40 C, 23 C and 85 C.

## Steps

1. At each temperature execute one automatic window movement as in SYQT-0001.
2. At each temperature send one lock command as in SYQT-0005.

## Expected result

1. At each temperature the window reaches its end position without further action.
2. At each temperature the door lock reaches the commanded position within 300 ms.
