## Preconditions

Complete system on the door bench; the diagnostic tester of the bench on the diagnostic interface; a fault is stored in the unit.

## Steps

1. Read the fault memory with the diagnostic tester.
2. Read the fault memory a second time.

## Expected result

1. The response returns the fault code and its status.
2. The second response returns the same fault code and status; reading did not change the memory.
