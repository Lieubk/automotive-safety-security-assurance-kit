## Preconditions

Complete system on the door bench, temperature 23 C; supply voltages 9 V, 13.5 V and 16 V.

## Steps

1. At each supply voltage execute one automatic window movement as in SYQT-0001.
2. At each supply voltage send one lock command as in SYQT-0005.

## Expected result

1. At each voltage the window reaches its end position without further action.
2. At each voltage the door lock reaches the commanded position within 300 ms.
