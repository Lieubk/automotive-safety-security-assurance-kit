## Preconditions

Complete system on the door bench with the rest-bus simulation of the body controller, supply 13.5 V, temperature 23 C; the lock position signal is measured.

## Steps

1. Send the lock command on the body CAN ten times, with the lock unlocked before each.
2. Send the unlock command ten times, with the lock locked before each.
3. Measure the time from the end of the message to the commanded lock position.

## Expected result

1. In each of the 20 runs the door lock has reached the commanded position within 300 ms after the end of the message.
