## Preconditions

Complete system on the door bench with the rest-bus simulation of the body controller, supply 13.5 V.

## Steps

1. Send the lock and the unlock command as defined in the OEM's message matrix.
2. Send the lock command with a wrong checksum.

## Expected result

1. The unit acknowledges each valid message on the body CAN and executes it.
2. The message with the wrong checksum is not executed.
