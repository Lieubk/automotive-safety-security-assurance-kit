## Preconditions

Complete system on the door bench; the diagnostic tester on the diagnostic interface; a fault is stored in the unit.

## Steps

1. Send the erase request with the diagnostic tester.
2. Read the fault memory with the diagnostic tester.

## Expected result

1. The erase request is accepted.
2. The response of the read returns no stored fault.
