Basis: SYI-0002 (Definition: one frame per 20 ms, state 2 is the second detent, a frame missing for 100 ms means no switch is pressed).

## Preconditions

Step software-on-hardware on the bench door-bench-electronics; the LIN simulation plays the switch panel; the motor is the load emulation; window position known; supply 13.5 V.

## Steps

1. The LIN simulation sends the frame with the closing switch in state 2 every 20 ms for 100 ms.
2. The LIN simulation stops sending frames and the bench waits 150 ms.

## Expected result

1. The bridge command changes to closing within 40 ms after the first frame.
2. The bridge command changes to off within 100 ms plus one 20 ms cycle after the last frame.
