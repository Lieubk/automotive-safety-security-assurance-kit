TEV-0001 Microsoft C/C++ compiler and its static analysis

statusapproved
toolMicrosoft C/C++ 19
impactTI2
detectionTD1
confidenceTCL1
asilB

Use cases

Builds of the integration steps on the host (BLD-0001, BLD-0002) and the static analysis of the units (SAR-0001). The delivered product is source code; the customer compiles it with the target compiler. An error of this tool could hide a fault of the code in a test or let a defect pass the analysis.

Classification rationale

A fault hidden by a wrong host build would show in the other host build with gcc (RUN-0001) or in the customer's tests on the target, which run on code compiled by another compiler. The analysis supplements reviews of the code, which do not rely on it.

TEV-0002 gcc and gcov for unit tests and structural coverage

statusapproved

Use cases

Builds and runs of the unit tests and the measurement of statement and branch coverage (RUN-0001). A wrong coverage figure could let an untested branch pass.

Classification rationale

The unit test cases are derived from the unit designs and reviewed against them; a branch without a test case is found in that review, independently of the measured figure. The tests also run with the Microsoft compiler in the integration steps.
