Scope

The components of ASIL B - WindowPos, AntiPinch, MotorDrive - and the interfaces of the basic software they use, measured against the system requirements of ASIL B the customer allocated to the software (SYR-0001, SYR-0002). The basic software itself is analysed by the customer.

Method

For each output of each component, the guide words no value, wrong value, too late, too early and stuck, followed to the movement of the window.

Results

Four findings, all closed: three carried by software requirements and the execution model, one left with the customer and argued. The analysis assumes the timing figures of the execution model, which only the customer's measurement on the target confirms.

Scope

Freedom from interference of WindowCmd (QM) with WindowPos, AntiPinch and MotorDrive (ASIL B) in the same software: memory, execution time and the exchange of commands.

Method

The dependent failure initiators shared memory, shared execution time and shared information, per pair of components.

Results
