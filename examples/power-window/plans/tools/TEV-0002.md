## Use cases

Builds and runs of the unit tests and the measurement of statement and branch coverage
(RUN-0001). A wrong coverage figure could let an untested branch pass.

## Classification rationale

The unit test cases are derived from the unit designs and reviewed against them; a branch
without a test case is found in that review, independently of the measured figure. The
tests also run with the Microsoft compiler in the integration steps.
