## Use cases

Builds of the integration steps on the host (BLD-0001, BLD-0002) and the static analysis
of the units (SAR-0001). The delivered product is source code; the customer compiles it
with the target compiler. An error of this tool could hide a fault of the code in a test
or let a defect pass the analysis.

## Classification rationale

A fault hidden by a wrong host build would show in the other host build with gcc (RUN-0001)
or in the customer's tests on the target, which run on code compiled by another compiler.
The analysis supplements reviews of the code, which do not rely on it.
