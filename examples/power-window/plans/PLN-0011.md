## Scope

Changes to items in a final baseline and to the delivered software, from the customer, from
problem reports or from the project itself.

## Approach

A change request names the items it affects; `python tools/traceability.py impact` gives
the items that become suspect. The safety manager judges the impact on functional safety
before the decision. Implemented changes are reviewed and the affected tests run again.

## Criteria

A change is decided by the software lead with the safety manager, and closed when the
review and the tests of its implementation passed.

## Environment and tools

Change requests as items under `records/changes/`; the trace engine.

## Responsibilities

Software lead: decisions. Safety manager: impact on safety. Configuration manager: records.
