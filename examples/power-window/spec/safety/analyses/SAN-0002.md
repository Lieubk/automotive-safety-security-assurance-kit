## Scope

Freedom from interference of WindowCmd (QM) with WindowPos, AntiPinch and MotorDrive
(ASIL B) in the same software: memory, execution time and the exchange of commands.

## Method

The dependent failure initiators shared memory, shared execution time and shared
information, per pair of components.

## Results

Three initiators, each answered by the design. Memory protection by the hardware is not
assumed: the argument rests on the interfaces and the checks of the code.
