## Definition

Signal `WindowSwitchRequest` in the cyclic frame of the door switch panel.

| Property | Value |
|---|---|
| Length | 3 bit |
| Values | 0 NONE, 1 OPEN, 2 CLOSE, 3 AUTO_CLOSE, 4 to 6 reserved, 7 signal not available |
| Cycle time | 20 ms |
| Loss | the signal counts as lost when no frame has been received for 100 ms |

## Dynamic behavior

OPEN and CLOSE are sent for as long as the switch is held in its first position.
AUTO_CLOSE is sent for as long as the switch is pulled to its second position, at least
for three frames; NONE follows when the switch is released.
