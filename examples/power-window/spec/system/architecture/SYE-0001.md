## Responsibility

The application software of the door module that moves the window. It evaluates the
switch request (SYI-0003) and the Hall sensor pulses (SYI-0001) and commands the motor
(SYI-0002). It tracks the window opening and the window speed, detects an obstacle
during closing and reverses the window.

Not part of this element: network management, diagnostics, supply monitoring and the
drivers of the microcontroller. They belong to the basic software, which the customer
provides and integrates.

Resources assigned to this element on the microcontroller of SYE-0002: 16384 bytes of
program flash, 1024 bytes of static RAM, 256 bytes of stack in each of its two tasks,
64 bytes of the interrupt stack, and 10 % of the processor time.

## Dynamic behavior

- Cycle times: 5 ms for position, speed, obstacle detection and motor command; 20 ms
  for the evaluation of the switch request.
- Time budget of the obstacle reaction: at most 20 ms from the moment the window speed
  has fallen 20 mm/s below its previous steady value until the motor command has
  changed to the opening direction.
- Start-up: the element is ready 50 ms after the reset is released, with the motor
  stopped.
- The window opening is not stored over a reset in release R1.0. After a reset it is
  unknown until the window has been driven against the fully open end stop once.
