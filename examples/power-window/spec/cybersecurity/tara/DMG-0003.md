title: The window cannot be moved from the switch panel

## Description

Requests from the driver's switch panel do not reach the window control; the window
stays where it is.

## Impact rationale

Operational moderate: the user of one vehicle loses the function while the attack
lasts. Safety negligible: a window that does not move traps nobody. Financial and
privacy negligible.
