## Description

Someone - a tuner, a careless workshop, an attacker - writes a changed program into the
door module in which the anti-pinch detection does not reverse the window (STRIDE:
tampering).

## Treatment rationale

Risk value 4. Shared with the customer: reprogramming, its security access and the
check of the image signature belong to the bootloader of the customer's basic software
(CMP-0006). CLM-0002 records the claim; the customer confirmed it at the TARA hand-over.
