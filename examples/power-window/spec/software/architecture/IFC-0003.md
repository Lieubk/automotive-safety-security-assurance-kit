## Description

Result of the obstacle detection. The three elements are updated together by
`AntiPinch_Step` every 5 ms and read as one record through `AntiPinch_GetStatus`.

- `reversal_request` is the only element with an effect on the motor. MotorDrive reads
  it in the cycle in which it changes and gives it priority over the movement command
  (SWR-0007). `reversal_request` is TRUE exactly while `state` is REVERSING.
- WindowCmd uses `state` to give up an automatic closing movement after a reversal.
- A consumer that cannot read the record (`AntiPinch_GetStatus` returns `E_NOT_OK`
  only for a null pointer) has an integration fault; there is no substitute value.
