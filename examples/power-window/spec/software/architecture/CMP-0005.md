## Purpose

The only component that commands the bridge driver. Because every motor command passes
through it, the priority of the reversal over all other commands is decided in one
place.

## Responsibility

- Takes the movement command of WindowCmd (IFC-0004) and the reversal request of
  AntiPinch (IFC-0003) and commands the bridge driver through IFC-0008. While the
  reversal request is set, the bridge is driven in the opening direction at 100 %,
  whatever the movement command says (SWR-0007).
- Raises the duty cycle from 30 % to 100 % within the first 100 ms of a movement
  started by the movement command.
- Switches the bridge off when, in a movement asked for by the movement command, the
  window speed (IFC-0002) has been 0 mm/s for 250 ms, which is the case at both end
  stops. A reversal is not switched off this way; it ends with the reversal request
  (SWR-0005).
- Publishes the direction in which the bridge is actually driven on IFC-0005.

It does not decide when the window moves and does not detect obstacles.

## Dynamic behavior

One cycle function, `MotorDrive_Step`, every 5 ms, last in the task. A change of the
reversal request is on the bridge inputs in the same cycle. The direction on IFC-0005
is the one written to the bridge in that cycle. After initialisation the bridge is off.
Worst-case execution time objective 60 us per cycle.
