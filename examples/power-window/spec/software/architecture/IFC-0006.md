## Description

The switch request of the body network (SYI-0003) as the communication stack of the
basic software hands it to the application. The stack unpacks the signal from the
frame and supervises its reception.

- When no frame has been received for 100 ms the stack delivers the invalid value 7
  until the next frame arrives.
- WindowCmd treats 4 to 7 as NONE (SWR-0009, criterion 3). A lost signal therefore
  ends a manual movement; an automatic closing movement continues, as it needs no
  request to be held.
- Before the first frame after start-up the element has its initial value NONE.
