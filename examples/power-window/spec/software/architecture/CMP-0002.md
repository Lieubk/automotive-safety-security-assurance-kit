## Purpose

Keeps the rules of the comfort functions - which switch request leads to which
movement - in one place, apart from everything that has to be developed to ASIL B.

## Responsibility

Turns the switch request (IFC-0006) into the movement command for MotorDrive
(IFC-0004): manual movement while the switch is held (SWR-0009) and automatic closing
after one touch (SWR-0008). It reads the window motion (IFC-0002), the detection status
(IFC-0003) and the motor state (IFC-0005) to end a movement at the closed end stop, to
give up automatic closing after a reversal, and to refuse automatic closing while the
window opening is not available.

It does not detect obstacles, does not command the bridge driver and provides no
interface to another component. Nothing it issues can keep the window closing against
a reversal request.

## Dynamic behavior

One cycle function, `WindowCmd_Step`, every 20 ms. Internal states: stopped, manual
opening, manual closing, automatic closing (VIEW-0002). A switch request that is lost
(no frame for 100 ms) or outside 0 to 3 is treated as NONE. After initialisation the
state is stopped. Worst-case execution time objective 120 us per cycle.
