## Description

The direction MotorDrive has written to the bridge driver in its last cycle. It is the
movement command of IFC-0004 unless a reversal request (IFC-0003) or a standstill at
an end stop has changed it.

- WindowPos counts the Hall pulses in this direction (SWR-0001) and references the
  window opening while it is "opening" (SWR-0002).
- AntiPinch supervises the movement while it is "closing" (SWR-0004).
- WindowCmd compares it with its movement command to notice a reversal or a stop at
  an end stop.

The consumers in the 5 ms task run before the provider and therefore see the direction
of the previous cycle; the delay of 5 ms is covered by the run-out of the drive
(SWR-0001, Analysis). A value above 2 is outside the specification; WindowPos refuses
the cycle, AntiPinch reverses a closing movement (SWR-0006).
