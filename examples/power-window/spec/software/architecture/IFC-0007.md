## Description

The "now" that belongs to the time stamps of the Hall edges. The integration code
reads the timer once at the start of each 5 ms cycle and passes the value to
`WindowPos_Step` as argument `now_us`. WindowPos uses it for one purpose: the time
since the last pulse (SWR-0003).

- The element has no initial and no invalid value; the timer runs from reset.
- All arithmetic on it is unsigned and modulo 2^32, so the wrap needs no special case.
- A Hall edge can be captured between the reading of the timer and the call of
  `WindowPos_Step`; its time stamp is then later than `now_us`. WindowPos treats this
  as "no time has passed since the last pulse".
- The value must come from the same timer as the time stamps of IFC-0001. A different
  time base would make the speed wrong without any means of detection in WindowPos.
