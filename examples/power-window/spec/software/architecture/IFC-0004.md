## Description

The way the command logic asks for a movement. The interface is QM: the command is a
wish of the comfort functions, and MotorDrive is built so that no value of it can
endanger the obstacle reaction - the reversal request of IFC-0003 always wins.

Constraints on its use:

- Called from `OsTask_Command_20ms` only. Tasks do not preempt each other, so the
  provider's cycle function never sees a half-written command.
- The provider does not report whether the command is carried out. The client reads
  the direction actually applied from IFC-0005.

Error behavior: on `E_NOT_OK` the client repeats the call in its next cycle with a
valid command; the window stays stopped in the meantime.
