## Statement

The software shall clear the reversal request when the window opening has grown by
120 mm since the request was set, when the window opening has reached 480 mm, or when
2 s have passed since the request was set, whichever comes first.

## Verification criteria

1. Request set at 300.0 mm: still set at 419.5 mm, clear at 420.0 mm.
2. Request set at 400.0 mm: still set at 479.5 mm, clear at 480.0 mm.
3. Request set with the window opening not available: still set after 1.995 s, clear
   after 2.000 s.
4. Request set at 300.0 mm, window opening at 40 mm/s: still set after 1.995 s, clear
   after 2.000 s (at about 380 mm).

## Analysis

The time limit ends a reversal that does not reach its position, for example when the
window opening is not available or the glass moves slowly against ice, so that the
motor is not driven without end. At the slowest steady speed of 80 mm/s (SYE-0002) 120 mm take
1.5 s; 2 s leave a margin of 0.5 s. A window that is blocked completely while opening
is referenced as fully open after 200 ms (SWR-0002), which ends the reversal through
the second condition.
