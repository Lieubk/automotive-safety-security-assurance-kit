## Statement

While the reversal request is set, the software shall command the bridge driver in the
opening direction at a duty cycle of 100 %, whatever movement command is present,
starting no later than 5 ms after the request was set.

## Verification criteria

1. Movement command "closing, 100 %", reversal request set: the direction signal of
   SYI-0002 shows "opening" and the duty cycle 100 % within 5 ms.
2. While the request stays set, the movement command is changed through stopped,
   opening and closing: direction signal and duty cycle do not change.
3. Request cleared: the bridge command follows the movement command again within 5 ms.

## Analysis

The reaction is taken where the bridge is commanded, so that the command logic (QM)
is not part of the path from detection to motor. Fulfilled by the reused motor
actuation without change; its reversal input was confirmed against this requirement
in the reuse analysis for release R1.0.
