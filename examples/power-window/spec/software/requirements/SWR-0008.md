## Statement

When the switch request changes to AUTO_CLOSE while the window opening is available,
the software shall issue the movement command "closing" until the window stands at an
opening of 5 mm or less, a switch request other than NONE follows, or the reversal
request is set.

## Verification criteria

1. AUTO_CLOSE for 60 ms, then NONE, at a window opening of 300 mm: the movement command
   is "closing" within 40 ms and stays so until the window speed has been 0 mm/s for
   200 ms at an opening of 5 mm or less; then it is "stopped".
2. OPEN while closing automatically: "closing" is withdrawn within 40 ms.
3. Reversal request set while closing automatically: the movement command is "stopped"
   within 40 ms and stays so after the request is cleared.
4. AUTO_CLOSE while the window opening is not available: no movement command.

## Analysis

Without a valid opening the window would close to the seal and be reversed there by
the obstacle detection (SWR-0004), hence the condition. 40 ms are two cycles of the
20 ms task and lie within the 100 ms of SYR-0003.
