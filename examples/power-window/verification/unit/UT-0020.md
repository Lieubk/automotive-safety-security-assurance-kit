Error cases of `AntiPinch_Step` in every state, with the values just outside each range
(961, 65534, 501, 3) and the limits of the ranges (960, 65535, 500, 0); error case of
`AntiPinch_GetStatus`. Design basis: UNT-0003, Error handling; SWR-0006.

## Preconditions

Test program of unit AntiPinch (`tests/unit/test_AntiPinch.c` with
`src/antipinch/AntiPinch.c`); no stubs. A step is written as (position, speed, drive
direction); positions in counts of 0.5 mm, speeds in mm/s. "Monitoring at p / v" means
`AntiPinch_Init` followed by 20 steps (p, v, closing). The status is read with
`AntiPinch_GetStatus` after every step named.

## Steps

1. `AntiPinch_Init`; steps (961, 0, stopped), (65534, 0, opening), (600, 501, opening),
   (600, 100, direction value 3).
2. 1 step (961, 0, closing).
3. `AntiPinch_Init`; steps (960, 500, closing), (0, 0, closing), (65535, 0, closing).
4. 1 step (600, 80, direction value 3).
5. `AntiPinch_Init`; 5 steps (600, 80, closing); 1 step (600, 501, closing).
6. 1 step (960, 150, opening).
7. 398 steps (961, 150, opening).
8. 1 more step (961, 150, opening).
9. Monitoring at 600 / 150; 1 step (961, 150, closing).
10. Monitoring at 600 / 150; 1 step (600, 150, direction value 255).
11. Call `AntiPinch_GetStatus` with a null pointer.

## Expected result

1. `E_NOT_OK` from every step; IDLE, request FALSE.
2. `E_NOT_OK`; REVERSING, request TRUE: reversal from the first closing cycle on.
3. `E_OK` from every step; SETTLING.
4. `E_NOT_OK`; REVERSING, request TRUE: a direction out of range does not end the closing
   movement.
5. `E_NOT_OK` from the last step; REVERSING, request TRUE.
6. `E_OK`; REVERSING, request TRUE: this reversal has no target position.
7. `E_NOT_OK` from every step; REVERSING, request TRUE.
8. `E_NOT_OK`; IDLE, request FALSE: the refused cycles were counted, 400 in total.
9. `E_NOT_OK`; REVERSING, request TRUE.
10. `E_NOT_OK`; REVERSING, request TRUE.
11. `E_NOT_OK`.
