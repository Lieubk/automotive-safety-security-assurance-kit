Boundary values 10 and 11 counts (5.0 mm and 5.5 mm) of the position, and the value 65535.
Design basis: UNT-0003, state MONITORING; SWR-0004, criterion 4.

## Preconditions

Test program of unit AntiPinch (`tests/unit/test_AntiPinch.c` with
`src/antipinch/AntiPinch.c`); no stubs. A step is written as (position, speed, drive
direction); positions in counts of 0.5 mm, speeds in mm/s. "Monitoring at p / v" means
`AntiPinch_Init` followed by 20 steps (p, v, closing). The status is read with
`AntiPinch_GetStatus` after every step named.

## Steps

1. Monitoring at 10 / 150; 10 steps (10, 100, closing).
2. Monitoring at 11 / 150; 2 steps (11, 100, closing).
3. Monitoring at 11 / 150; steps (11, 100, closing), (10, 100, closing), (10, 100, closing).
4. 2 steps (11, 100, closing).
5. Monitoring at 65535 / 150; 2 steps (65535, 100, closing).

## Expected result

1. MONITORING, request FALSE.
2. MONITORING, request FALSE after the first step; REVERSING, request TRUE after the second.
3. MONITORING, request FALSE: a drop that continues below the zone limit is not confirmed.
4. MONITORING, request FALSE after the first step; REVERSING, request TRUE after the second.
5. As in step 2: an unknown position counts as inside the protected zone.
