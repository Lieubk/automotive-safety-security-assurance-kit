Boundary values 399 and 400 cycles, without a target position and with a target position
that is not reached. Design basis: UNT-0003, state REVERSING; SWR-0005, criteria 3 and 4.

## Preconditions

Test program of unit AntiPinch (`tests/unit/test_AntiPinch.c` with
`src/antipinch/AntiPinch.c`); no stubs. A step is written as (position, speed, drive
direction); positions in counts of 0.5 mm, speeds in mm/s. "Monitoring at p / v" means
`AntiPinch_Init` followed by 20 steps (p, v, closing). The status is read with
`AntiPinch_GetStatus` after every step named.

## Steps

1. Monitoring at 65535 / 150; 2 steps (65535, 100, closing).
2. 399 steps (65535, 150, opening).
3. 1 more step.
4. Monitoring at 600 / 150; 2 steps (600, 100, closing); 399 steps (600, 0, opening).
5. 1 more step.

## Expected result

1. REVERSING, request TRUE.
2. REVERSING, request TRUE.
3. IDLE, request FALSE.
4. REVERSING, request TRUE.
5. IDLE, request FALSE.
