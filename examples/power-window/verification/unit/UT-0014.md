Normal case of the detection. Design basis: UNT-0003, state MONITORING; SWR-0004,
criterion 1.

## Preconditions

Test program of unit AntiPinch (`tests/unit/test_AntiPinch.c` with
`src/antipinch/AntiPinch.c`); no stubs. A step is written as (position, speed, drive
direction); positions in counts of 0.5 mm, speeds in mm/s. "Monitoring at p / v" means
`AntiPinch_Init` followed by 20 steps (p, v, closing). The status is read with
`AntiPinch_GetStatus` after every step named.

## Steps

1. Monitoring at 600 / 150; 10 further steps (600, 150, closing).
2. 1 step (600, 129, closing).
3. 1 step (599, 129, closing).
4. 1 step (598, 20, stopped); 1 step (598, 0, opening).
5. Monitoring at 300 / 180; 2 steps (300, 0, closing).

## Expected result

1. MONITORING, request FALSE, reference speed 150.
2. MONITORING, request FALSE, reference speed 150 (held).
3. REVERSING, request TRUE, reference speed 0: set in the second cycle of the drop, 10 ms
   after it at the latest.
4. REVERSING, request TRUE after each step.
5. MONITORING, request FALSE after the first step; REVERSING, request TRUE after the second.
