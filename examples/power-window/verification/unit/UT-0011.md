Error cases of `WindowPos_Step`, with direction values 3 and 255 (just outside and far
outside the range). Design basis: UNT-0002, function contract and Error handling.

## Preconditions

Test program of unit WindowPos (`tests/unit/test_WindowPos.c` with
`src/windowpos/WindowPos.c`). `HallCapture_GetSnapshot` is replaced by a stub that
returns prepared pulse data and a prepared return value. "Referenced" means 40 steps
with direction opening and no pulse; unless a period is given, the pulse data keeps the
speed at 0 mm/s.

## Steps

1. Reference the position; one step closing with 2 pulses 4000 us apart.
2. 10 new pulses pending, period 2000 us. Step with direction 3; step with direction 255.
3. Step with direction closing.
4. 4 new pulses pending, period 5000 us; the stub returns `E_NOT_OK`. Step closing.
5. The stub returns `E_OK` again. Step closing.

## Expected result

1. Position 958, speed 125.
2. Both steps return `E_NOT_OK`; the stub was not called; position 958, speed 125.
3. `E_OK`; the stub was called once; position 948, speed 250.
4. `E_NOT_OK`; position 948, speed 250.
5. `E_OK`; position 944, speed 100.
