Boundary values of both counters. Design basis: UNT-0001, data `HallCapture_PulseCount`
(wraps) and `HallCapture_RejectedCount` (stops at 65535).

## Preconditions

Test program of unit HallCapture (`tests/unit/test_HallCapture.c` with
`src/windowpos/HallCapture.c`). The two exclusive area services are replaced by stubs
that count their calls. "Read" means a call of `HallCapture_GetSnapshot` that returns
`E_OK`.

## Steps

1. `HallCapture_Init`, 65535 edges 1000 us apart, the first at 0; read.
2. One more edge; read.
3. One more edge; read.
4. `HallCapture_Init`, edge at 0, then 65535 edges with time stamp 1; read.
5. One more edge with time stamp 1; read.

## Expected result

1. `pulse_count` 65535.
2. `pulse_count` 0.
3. `pulse_count` 1, `period_us` 1000, `rejected_count` 0.
4. `rejected_count` 65535.
5. `rejected_count` 65535, `pulse_count` 1.
