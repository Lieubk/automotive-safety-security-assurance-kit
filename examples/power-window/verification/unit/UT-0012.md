Error case of both read functions. Design basis: UNT-0002, function contracts.

## Preconditions

Test program of unit WindowPos (`tests/unit/test_WindowPos.c` with
`src/windowpos/WindowPos.c`). `HallCapture_GetSnapshot` is replaced by a stub that
returns prepared pulse data and a prepared return value. "Referenced" means 40 steps
with direction opening and no pulse; unless a period is given, the pulse data keeps the
speed at 0 mm/s.

## Steps

1. `WindowPos_Init`; call `WindowPos_GetPosition` and `WindowPos_GetSpeed` with a null pointer.
2. Reference the position; call both functions with a null pointer again.

## Expected result

1. `E_NOT_OK` from both.
2. `E_NOT_OK` from both. The test program ends normally.
