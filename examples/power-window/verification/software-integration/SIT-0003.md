Data flow within one cycle of the 5 ms task. Basis: IFC-0002 (consumers in the 5 ms task
see position and speed of the same cycle), IFC-0003 (MotorDrive reads the reversal
request in the cycle it changes), VIEW-0004 (order WindowPos, AntiPinch, MotorDrive);
the values from the criteria of SWR-0004.

## Preconditions

Test program of step detection (`tests/integration/test_detection.c`), built by
`tests/integration/run_tests.py` from the units of WindowPos (CMP-0003) and AntiPinch
(CMP-0004), with the doubles of WindowCmd, MotorDrive and the platform. The MotorDrive
double publishes the motor state the test sets and records the reversal request and the
speed the 5 ms task hands to it. A cycle is one run of `OsTask_Control_5ms` by the
platform double, 5 ms after the previous one, with the capture time set to the time of
the cycle; the edges of a cycle reach the capture interrupt before the task runs.
"Referenced" means: start, motor state opening, 40 cycles without edges. Positions in
counts of 0.5 mm.

## Steps

1. Referenced; motor state closing; edges every 3333 us (150 mm/s) for 200 cycles.
2. Edges every 3870 us (129 mm/s); 1 cycle.
3. 1 more cycle.

## Expected result

1. AntiPinch state MONITORING; speed handed to MotorDrive 150; reversal request handed to MotorDrive FALSE.
2. Speed handed to MotorDrive 129; reversal request FALSE in AntiPinch and at MotorDrive: first cycle of the drop.
3. AntiPinch state REVERSING, request TRUE; the request handed to MotorDrive in this same cycle TRUE.
