Interface case for the two consumers of the motor state in this step. Basis:
IFC-0005 (WindowPos counts in the applied direction; AntiPinch supervises while it is
closing; a value above 2 is outside the specification, AntiPinch reverses a closing
movement), SWR-0001 (run-out pulses in the direction driven last), SWR-0006.

## Preconditions

Test program of step detection (`tests/integration/test_detection.c`), built by
`tests/integration/run_tests.py` from the units of WindowPos (CMP-0003) and AntiPinch
(CMP-0004), with the doubles of WindowCmd, MotorDrive and the platform. The MotorDrive
double publishes the motor state the test sets and records the reversal request and the
speed the 5 ms task hands to it. A cycle is one run of `OsTask_Control_5ms` by the
platform double, 5 ms after the previous one, with the capture time set to the time of
the cycle; the edges of a cycle reach the capture interrupt before the task runs.
"Referenced" means: start, motor state opening, 40 cycles without edges. Positions in
counts of 0.5 mm.

## Steps

1. Referenced.
2. Motor state closing; edges every 3000 us for 12 cycles (20 edges).
3. Motor state stopped; edges every 3000 us for 2 cycles (3 edges).
4. Motor state opening; edges every 3000 us for 6 cycles (10 edges).
5. Motor state closing; 1 cycle.
6. Motor state 3; no edges; 1 cycle.

## Expected result

1. Position 960.
2. Position 940.
3. Position 937: the run-out edges count in the direction driven last.
4. Position 947; AntiPinch state IDLE: no supervision while opening.
5. AntiPinch state SETTLING: the supervision of the closing movement begins.
6. AntiPinch reversal request TRUE, and the reversal request handed to MotorDrive in the same cycle TRUE.
