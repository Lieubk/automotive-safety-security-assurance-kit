Criteria 1 to 4 of SWR-0006 and the closing sentence of its criteria. The components that
deliver these inputs never produce such values, so they are put into the input of the
obstacle detection by the platform double, as a measurement and calibration tool
overwrites a signal on the control unit (PLN-0005).

## Preconditions

Test program `tests/qualification/test_qualification.c`, built by
`tests/qualification/run_tests.py` from the software of the last integration step
(PLN-0004, step application) and the platform double; stimuli and measurement points as
PLN-0005 names them. A cycle is 5 ms; every fourth cycle the 20 ms task follows.
"Referenced": start, switch request OPEN for 300 ms with the window at the open end
stop (no pulses), then NONE for 40 ms. "A movement by n pulses": the switch starts the
drive, n pulses follow 3 ms apart from 3 ms after the drive started, and the switch is
released so that the drive stops in the cycle of the last pulse. "Pulses at v mm/s":
a pulse train with the period that 0.5 mm takes at v mm/s. Positions in counts of 0.5 mm.

## Steps

1. Start; CLOSE; pulses at 150 mm/s; the window opening value 961 handed to the detection for one cycle: in the first cycle of the closing movement, after 50 ms, after 200 ms (each time after a new start).
2. As step 1 with the window speed 501 mm/s.
3. As step 1 with the drive direction value 3, in the second cycle instead of the first.
4. For each of the three values: after 50 ms of closing, 1.995 s and 2.000 s after the request was set.
5. Each value for one cycle with the drive stopped, and again while it opens.

## Expected result

1. Request set in the cycle of the wrong value, each time.
2. As 1.
3. As 1.
4. Set at 1.995 s, clear at 2.000 s (time limit of SWR-0005; the opening is not available, so no travel ends it).
5. Request clear.
