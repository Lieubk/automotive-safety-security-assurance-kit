Criteria 1 to 4 of SWR-0005. The request is set by a speed drop as in SQT-0004; the
position at which it is set is the reference of criteria 1 and 4.

## Preconditions

Test program `tests/qualification/test_qualification.c`, built by
`tests/qualification/run_tests.py` from the software of the last integration step
(PLN-0004, step application) and the platform double; stimuli and measurement points as
PLN-0005 names them. A cycle is 5 ms; every fourth cycle the 20 ms task follows.
"Referenced": start, switch request OPEN for 300 ms with the window at the open end
stop (no pulses), then NONE for 40 ms. "A movement by n pulses": the switch starts the
drive, n pulses follow 3 ms apart from 3 ms after the drive started, and the switch is
released so that the drive stops in the cycle of the last pulse. "Pulses at v mm/s":
a pulse train with the period that 0.5 mm takes at v mm/s. Positions in counts of 0.5 mm.

## Steps

1. Referenced; closing to 300.0 mm, drop to 129 mm/s until the request is set; then pulses at 150 mm/s, cycle by cycle.
2. As step 1, the drop at 400.0 mm or less.
3. Start without reference; closing, drop until the request is set; pulses at 150 mm/s; 1.995 s and 2.000 s after the request was set.
4. As step 1, then pulses at 40 mm/s; 1.995 s and 2.000 s after the request was set.

## Expected result

1. Set while the position is less than 240 counts (120 mm) above the position at which it was set; clear in the cycle the position reaches it.
2. Set while the position is below 960; clear in the cycle it reaches 960 (480.0 mm).
3. Set at 1.995 s, clear at 2.000 s.
4. Set at 1.995 s, clear at 2.000 s; the position then 150 to 170 counts above the start of the reversal (about 380 mm).
